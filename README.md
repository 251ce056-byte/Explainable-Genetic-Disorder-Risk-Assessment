
# Explainable Genetic Disorder Risk Assessment System

## Project Description
A Machine Learning project that predicts genetic disorder categories using a Decision Tree Classifier.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Flask
- Streamlit
- Matplotlib

## Model
Decision Tree Classifier

## Model Performance
- Training Accuracy: 61.57%
- Testing Accuracy: 59.64%
- Cross-validation Macro F1 Score: 51.00%

## Features
- Genetic disorder prediction
- Feature importance visualization
- Model performance display

## Disclaimer
This project is for educational purposes only and is not a medical diagnosis tool.

## Run Application
streamlit run app.py
